## Symptom

## Evidence

The cause, or ranked hypotheses with the evidence for and against each and the next measurement that separates them.

## Proposed fix
File, symbol, behaviour change; risk; tests (the failing test that reproduces the problem first).

## Workaround for the user
If any, without changing their data without consent.
