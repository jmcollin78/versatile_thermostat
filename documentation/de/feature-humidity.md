# Externer Luftfeuchtigkeitssensor

VTherm kann `current_humidity` für `over_switch`, `over_valve` und `over_climate` von einem externen Sensor übernehmen.

Öffnen Sie im Konfigurationsmenü **Luftfeuchtigkeit**, aktivieren Sie die Option und wählen Sie einen Sensor. Bleibt die Auswahl leer, verwendet VTherm den automatisch am Gerät des Raumtemperatursensors erkannten Sensor. Die Feuchtigkeit beeinflusst die Temperaturregelung nicht.
