# Externí senzor vlhkosti

VTherm může pro termostaty `over_switch`, `over_valve` a `over_climate` poskytovat `current_humidity` z externího senzoru.

V konfigurační nabídce otevřete **Vlhkost**, zapněte volbu a vyberte senzor. Pokud výběr necháte prázdný, VTherm použije senzor automaticky nalezený na zařízení pokojového teploměru. Vlhkost neovlivňuje regulaci teploty.
